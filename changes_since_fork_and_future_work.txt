Changes since fork:
* Finding a route is not limited to EV136.
* Routes work when overlapping roads, such as inside spiraling tunnels.
* Routes work over ferry crossings.
* Can find speedlimits without hardcoding it for EV136.
* Better documentation and overall concistency.
* Add config.
* Close the visual gap in frontend at the end of elevation-curve in the skyplot.
* More accurate terrain analysis along borders between .tif files.
* The backend can handle multiple (different) requests from multiple clients, but they are queued (only one is served at a time).
* DOP values can now be calculated as forcast. The number of days in the future is
  determined by NR_FORCAST_DAYS from config.py.
  Satellites drift kilometers (exponentially) in a week (which is neglible at 20'000km distance).
  Ephemeris data should be valid for a few weeks.
* The option "Vegsystemreferanse" in the frontend is not used and is thoroughly removed.
